# Debug Deployment Internship — Front-End Exercises

A collection of three small web-development exercises created during a front-end internship/training period.

## Projects

- **To-do List** — a task-list UI exercise
- **Netflix Home Page** — a static streaming-service landing-page recreation
- **Quiz** — a simple single-page multiple-choice quiz

## Technology

- HTML
- CSS
- JavaScript
- Static image assets

## Run locally

Open the relevant HTML page in the selected project folder in a modern browser. Keep the local images and styles in their current relative locations.

## Scope

These are front-end learning exercises. They do not connect to Netflix or a live quiz service, and they do not include authentication, server-side storage, or real streaming functionality.

## Suggested improvements

Add project-specific screenshots, accessibility checks, responsive layouts, input validation, and a separate README inside each exercise if the projects grow.
